# Acme Shop Telemetry Schema

Schema URL: `https://acme.example/schemas/0.2.0`

Every signal below is what the Acme services are allowed to emit. Anything else
that reaches the pipeline is reported as a finding by `weaver registry live-check`.

## Attributes

### Acme Order Attributes

Attributes describing an order flowing through the Acme Shop.

| Attribute | Type | Description |
| --- | --- | --- |
| `acme.customer.tier` | enum | Commercial tier of the customer that placed the order. Allowed values: `free`, `plus`, `enterprise`. |
| `acme.order.id` | string | Opaque identifier of the order, unique for the lifetime of the shop. |
| `acme.order.item_count` | int | Number of distinct line items in the order. |

### Acme Payment Attributes

Attributes describing a payment authorization attempt.

| Attribute | Type | Description |
| --- | --- | --- |
| `acme.payment.decline_reason` | enum | Why the payment authorization was declined. Allowed values: `insufficient_funds`, `fraud_suspected`, `expired_card`. |
| `acme.payment.method` | enum | Instrument used to authorize the payment. Allowed values: `card`, `wire`, `wallet`. |

### Acme Pipeline Attributes

Attributes added by the collector pipeline rather than by application code. They are declared here because telemetry that the pipeline enriches is still telemetry the schema is responsible for.

| Attribute | Type | Description |
| --- | --- | --- |
| `acme.agent.name` | string | Name of the sidecar collector that first received the signal. |
| `acme.log.service_name` | string | Service whose log records a log-derived metric counted. |
| `acme.log.severity` | string | Severity text of the log records counted by a log-derived metric. |
| `acme.pipeline.tier` | enum | Collector tier that last processed the signal. Allowed values: `agent`, `gateway`. |

### Acme Service Attributes

Attributes describing an Acme service instance.

| Attribute | Type | Description |
| --- | --- | --- |
| `acme.service.tier` | enum | Position of the service in the Acme deployment topology. Allowed values: `edge`, `core`. |
